# Privacy

Checklist content stays in the app’s local storage and is exchanged only with its paired Apple device through WatchConnectivity. There is no external server, analytics, account, or advertising.

The complication receives a small local App Group snapshot containing the remaining count and next task title. Task text is marked privacy-sensitive. Face placement and system privacy settings determine what is visible.

Reminders require explicit notification permission on iPhone. Notification content includes the task title and group; system settings control previews. System keyboard dictation follows Apple’s settings and processing behavior. The app does not capture microphone audio itself.

Archiving is reversible and retained across device synchronization. This version has no permanent in-app purge operation. Uninstalling one copy does not erase the paired device’s copy.
